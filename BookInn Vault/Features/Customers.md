# Features — Customers

## Purpose
This document provides the status of the customer/guest management module in **BookInn**.

---

## What is Currently Implemented

> [!IMPORTANT]
> **Status: Not Implemented**
> 
> There is **no separate Customer/Guest model or feature** implemented. Guest information (`guestName`, `guestPhone`) is stored inline directly inside the `Booking` schema.
