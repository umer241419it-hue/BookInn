# Assets Overview

## Purpose
This directory stores static diagrams, screenshots, and visual assets referenced throughout the **BookInn Vault**.

---

## What is Currently Implemented

Visual diagrams in the vault are rendered dynamically using **Mermaid** in Markdown files (e.g., [[Architecture]], [[Backend/Request Flow]], [[Database/Relationships]]).

---

## Directory Structure:
- `Assets/Screenshots/` — Reserved for UI or terminal output screenshots.
- `Assets/Images/` — Reserved for general images.
- `Assets/Diagrams/` — Reserved for static image export diagrams.
